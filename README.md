# 🌿 Jelajah Jember

Platform informasi wisata alam Kabupaten Jember yang dibangun sebagai proyek web statis berbasis HTML, CSS, dan JavaScript murni — tanpa framework atau dependensi eksternal.

---

## 📌 Tentang Proyek

**Jelajah Jember** adalah website yang menampilkan keindahan destinasi wisata alam di Kabupaten Jember, Jawa Timur. Mulai dari pantai-pantai eksotis berpasir putih, air terjun tersembunyi di balik hutan tropis, puncak gunung dengan jalur pendakian terpanjang di Jawa, hingga agrowisata perkebunan kopi di lereng pegunungan — semuanya dikemas dalam tampilan yang modern dan responsif.

---

## ✨ Fitur

- **Hero Section** — Landing page dengan overlay visual, statistik kategori wisata, dan CTA navigasi.
- **Kategori Wisata** — Pengelompokan destinasi ke dalam 4 kategori: Pegunungan & Perbukitan, Pantai & Laut, Agrowisata & Perkebunan, dan Air Terjun.
- **Destinasi Unggulan** — Grid kartu destinasi dengan gambar, rating, harga tiket masuk, dan deskripsi singkat.
- **Filter Destinasi** — Tombol filter interaktif untuk menyaring kartu berdasarkan kategori (Pantai, Gunung, Air Terjun, Hutan) dengan animasi fade-in.
- **Wishlist / Simpan** — Tombol simpan pada tiap kartu destinasi untuk menandai favorit.
- **Galeri Alam** — Grid galeri foto dengan layout bento-style.
- **CTA Newsletter** — Form berlangganan email dengan feedback sukses setelah submit.
- **Footer Lengkap** — Tautan navigasi, daftar destinasi, kategori, info kontak, dan ikon media sosial (Instagram, YouTube, Facebook, X).
- **Navbar Responsif** — Navbar dengan efek scroll blur dan hamburger menu untuk tampilan mobile.
- **Smooth Scroll & Active Link** — Navigasi aktif mengikuti section yang sedang terlihat di viewport menggunakan Intersection Observer.
- **Scroll Reveal Animation** — Elemen muncul dengan animasi stagger saat di-scroll ke dalam viewport.
- **Custom Cursor** — Kursor kustom dengan efek ring lag, trail partikel warna-warni, dan ripple saat klik.

## 🗂️ Struktur Proyek

```
Wisata Alam/
├── index.html    # Markup utama seluruh halaman
├── style.css     # Seluruh styling (layout, komponen, animasi)
└── script.js     # Interaktivitas (navbar, filter, cursor, reveal, dsb.)
```

## 🚀 Cara Menjalankan

Tidak memerlukan instalasi atau build tool apapun. Cukup buka file langsung di browser:

```
Klik dua kali index.html
```

Atau gunakan ekstensi **Live Server** di VS Code untuk preview dengan hot-reload.
